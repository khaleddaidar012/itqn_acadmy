# تشغيل النظام

يتطلب Node.js 24 وخادمًا بقرص دائم. أضف إلى `.env.local`:

```
ITQAN_ADMIN_EMAIL=your-real-email@example.com
ITQAN_ADMIN_PASSWORD=choose-a-long-unique-password
ITQAN_ADMIN_NAME=مدير الأكاديمية
ITQAN_CANCEL_HOURS=12
```

يُنشأ المدير مرة واحدة عند أول طلب. كلمة المرور لا تقل عن 12 حرفًا. لا تشاركها داخل الريبو. بعد الإنشاء يمكنك حذف متغير كلمة المرور. البيانات في `.data/itqan.sqlite`؛ انسخها احتياطيًا باستخدام أدوات SQLite. شغّل `npm run dev` ثم افتح `/ar/login`. للإنتاج `npm run build` ثم `npm start` خلف HTTPS. النشر الثابت القديم لا يدعم النظام الجديد.

يمكن تغيير مسار البيانات باستخدام `ITQAN_DATA_DIR` إلى مسار قرص دائم. `npm run test:system` يشغل اختبارات على منفذ 3107 ببيانات مؤقتة مستقلة ثم يحذفها. `npx tsc --noEmit` يفحص الأنواع. لا تشغل الاختبار وbuild بالتوازي لأنهما يستخدمان `.next` نفسه. كل الحسابات تستطيع تغيير كلمة المرور من «حسابي»، مما يبطل جلساتها على الأجهزة الأخرى.

الدخول للحصة يسجل وقت الضغط على زر الدخول من الخادم، ولا يثبت حضور اجتماع خارجي. لا يُغلق اجتماع خارجي فعليًا قبل تنفيذ تكامل مزود الاجتماعات. نسبة الحفظ تعتمد على عدد الصفحات المتقنة المسجل بواسطة المعلم، وليست تحققًا آليًا من التسميع.
