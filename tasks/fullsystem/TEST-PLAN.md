# خطة اختبار نظام إتقان

تاريخ إعداد الخطة: 14 أكتوبر 2026. النطاق: النسخة الحالية على fullsystem، مع فصل اختبارات المتبقي قبل الإطلاق. هذه خطة تنفيذ، وليست شهادة بأن كل الحالات نجحت. حالات النسخة الحالية لم تُنفذ ضمن هذه الجولة، والحالات المستقبلية محجوبة لحين تنفيذها. لا يمكن ضمان حصر كل تركيب ممكن للمدخلات؛ الخطة تغطي المسارات الرئيسية والسلبية والحدود والصلاحيات والتشغيل والمتبقي المعروف.

## قبل البدء
- اقرأ SYSTEM-GUIDE.md. شغل npm run dev وافتح http://localhost:3000/ar/login.
- بيانات المدير في .local/admin-credentials.txt؛ لا تنسخ كلمة المرور في تقرير الاختبار أو Git.
- الاختبارات اليدوية تضيف بيانات محلية؛ استخدم أسماء QA وبريدًا اختباريًا. الحالات الحساسة لكلمة المرور وحدود المحاولات على حسابات اختبار فقط.
- جهز T-A معلم 120 EGP، وT-B معلم 12 USD، وT-M مسؤول جداول؛ S-A وS-B طالبين؛ P-A وP-B وليي أمر. اربط S-A بـ T-A وP-A، وS-B بـ T-B وP-B. لإنجاز اختبار ولي أمر لطفلين اربط الطالبين به مؤقتًا ثم أعد الوضع الأصلي.
- استخدم ملفات متصفح منفصلة أو سجل الخروج بين الأدوار. لا تختبر الخصوصية بالأزرار وحدها؛ حالات API تحتاج فحص طلبات المتصفح وإعادة إرسالها بعد تعديل المعرفات.
- كل المواعيد بتوقيت القاهرة. سيناريوهات الثواني وحدود الوقت الدقيقة تُجرّب آليًا على قاعدة مؤقتة بساعة ثابتة؛ لا تعدل ساعة الجهاز أو بيانات الطلاب الحقيقيين.
- اختر الحالة: ناجح / فاشل / محجوب / لم يُنفذ. أضف دليلًا وملاحظة عند الفشل. الحالات المستقبلية محجوبة حتى تنفيذ الميزة، وليست ناجحة.

## تجربة سريعة من أولها لآخرها
1. سجل S-A طالبًا بمواد الحفظ والتجويد، ثم أكد حسابه من قسم الطلاب وطلبات التسجيل بعد مراجعة الاشتراك.
2. ادخل كأدمن وأنشئ T-A بأجر 120 EGP وP-A، واربط ولي الأمر بالطالب.
3. عين حصة مستقبلية مدتها 30 دقيقة، ثم تحقق منها بحسابات الطالب والمعلم وولي الأمر.
4. عند موعدها سجل دخول T-A ثم سجل حضور الطالب ووثق 60 صفحة مع ملاحظة.
5. أنه الحضور؛ راجع دقائق الحضور والمستحق وحالة الطالب ونسبة الحفظ بحساب كل دور.
6. جرب حصة أخرى بإلغاء مسموح، وأخرى بإلغاء متأخر، وأخرى بتأجيل، وراجع بقاء السجل القديم.
7. ادخل S-B وP-B وT-B وتأكد أن بيانات S-A غير متاحة للحسابات غير المخولة.

## أوامر الاختبار الآلي الحالية

شغل الأوامر منفصلة، وليس في الوقت نفسه. المنفذ 3107 للاختبارات، و3000 للتطوير. اختبار Node أو D1 proxy قد يعيد توليد .next؛ عند الرجوع للتطوير أعد تشغيله إذا ظهر خطأ في ملفات البناء.

~~~powershell
npm run test:system
npm run test:system:d1
npm run build:cloudflare
npm run test:system:worker
~~~

السكربت الموجود tests/system.mjs يغطي تسجيل الأدوار وعزل البيانات وربط ولي الأمر ورفض الجدولة غير المسموحة وتعارض المواعيد والتكرار والتراجع والطلبات المتزامنة والتأجيل والحضور والتقدم وتثبيت الأجر وإخفاء أجور الآخرين وتغيير كلمات المرور والجلسات وأمثلة احتساب الدقائق. لا يغطي جميع الصفوف اليدوية في هذه الخطة، ولا يختبر Zoom أو قاعدة Cloudflare المنشورة. نجاحه السابق موثق في README؛ لم تُعد كل الحالات تلقائيًا لمجرد إنشاء هذه الخطة.
