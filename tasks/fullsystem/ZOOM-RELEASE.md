# إتاحة Zoom لحسابات معلمين مستقلة

## الحالة

التطوير يستخدم تطبيق user-managed في Development. نجاح حساب مالك التطبيق لا يثبت إمكانية تثبيت التطبيق بحساب معلم خارجي. لا تغيّر إعدادات الموافقة العامة للحساب لمعالجة هذا القيد.

## المسار المطلوب

1. افتح التطبيق في Zoom Marketplace، ثم Production → Beta Test → Share App.
2. جهّز بيانات التطبيق ووصف الوظائف والتصميم التقني، وروابط سياسة الخصوصية والشروط والدعم التي يراجعها مالك الأكاديمية. هذه الروابط لم تُنشأ أو تعتمد تلقائيًا.
3. للحسابات خارج حساب مالك التطبيق استخدم Request to Share بعد استكمال متطلبات Zoom. الرابط يتطلب موافقة Zoom، ولا يكفي رابط Local Test الخاص بالتطوير.
4. عند الموافقة، راجع بيانات Production المنفصلة عن Development، وعناوين callback وwebhook، ثم خطّط لتحويل الخدمة وإعادة موافقة المعلمين. لا تستخدم توكن Development مع Client ID/Secret من Production.
5. حافظ على مفتاح تشفير التفويضات الحالي أثناء الانتقال. اختبر معلمًا خارجيًا واحدًا قبل التعميم.

## وصف تقني للمراجعة

- الغرض: تجهيز اجتماع مستقل للحصة من حساب معلمها، وفتح رابط المضيف للمعلم وحده، ورابط الانضمام لطالب الحصة أو ولي أمره.
- تفويض كل معلم مستقل، مع state عشوائي أحادي الاستخدام مرتبط بجلسة المعلم. تخزن access/refresh tokens بتشفير AES-256-GCM في D1؛ لا تدخل التوكنات النسخ المحمولة ولا تعاد للمتصفح.
- الصلاحيات: user:read:user، meeting:write:meeting، meeting:read:meeting، meeting:read:participant، meeting:update:status للإغلاق التلقائي. لا يطلب التطبيق صلاحيات admin ولا تسجيل الصوت أو الفيديو.
- تستخدم webhooks موقعة مع فحص نافذة زمنية، وتُطابق الأحداث باجتماع معروف وحساب المضيف. لا يستخدم اسم المشارك لإثبات هويته. يخزن سجل الحضور أوقاتًا ومعرفات أحداث ومعرفات مشاركين مجزأة؛ لا يحتفظ بالنص الكامل للإشعارات.
- اسم وبريد Zoom للمعلم محفوظان لعرض الربط والتحقق منه. تخزن روابط الانضمام للاجتماعات؛ رابط المضيف يقرأ عند الطلب ويعاد للمعلم فقط دون حفظه.
- الانقطاع وإعادة الدخول والأجهزة المتعددة تعالج بفترات حضور مدمجة ومقصوصة بموعد الحصة. البريد غير المتاح أو غير المطابق للطالب يحتاج مراجعة يدوية.
- فصل الربط يستدعي إلغاء التفويض في Zoom ويحذف الاتصال المخزن. السجلات التاريخية للحصص والحضور لا تُمحى بهذا الفصل؛ سياسة الاحتفاظ والحذف النهائي يجب أن يحددها مالك الأكاديمية قبل اعتماد سياسة الخصوصية.

## قبول التجربة الخارجية

- ربط حساب Zoom مختلف للمعلم دون مشاركة كلمة مروره مع الأكاديمية.
- إعادة الدخول بعد انتهاء access token دون طلب موافقة جديدة ما دام refresh token صالحًا.
- حصة بمعلم وطالب بحساب Zoom مختلف، وفحص السجلات الفعلية لتسجيل الطالب أو تحديد سبب عدم التطابق.
- إنهاء تلقائي ناجح وتسجيل خروج المشاركين عبر webhook، مع عدم إغلاق أي اجتماع آخر.
- صلاحيات الطالب وولي الأمر لا تتيح الوصول إلى رابط المضيف أو توكنات المعلم أو حصص طالب آخر.
